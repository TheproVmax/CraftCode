04 / ABOUT CRAFTCODE

Curiosity
over memorizing.

CraftCode is about learning coding by experimenting, creating and figuring things out.

Whether you're completely new or already know a little, the goal is to build your skills while creating things you can actually use and show.

Instead of just learning what code does, learn how to make it do something.

05 / QUESTIONS

Before you start.

Do I need coding experience? +
No. Courses are designed to accommodate beginners and learners who already have some experience.
Where do classes happen? +
Classes are online. Scheduling and the platform used for lessons can be discussed when signing up.
What do I need? +
A computer and an internet connection. Specific software requirements depend on the course.
What will I actually learn? +
You'll work on coding concepts through projects, including games, animations, creative coding and debugging.
